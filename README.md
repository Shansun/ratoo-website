# Ratoo - Local Retail Marketing Website

A modern, highly-optimized marketing website for Ratoo, a local retail platform that connects customers with local businesses. This website showcases the brand and its offerings with a focus on rich user experience, exceptional performance, and stunning visual design.

## 🚀 Features

### Design & Aesthetics
- **Modern, minimalist design** with a friendly color palette
- **High-quality typography** using Inter font
- **Responsive design** that looks great on all devices
- **Smooth animations** powered by Framer Motion
- **Professional visual elements** with optimized graphics

### Core Pages
- **Landing Page** (`/`) - Single-page application with rich, animated sections
- **About Us** (`/about`) - Company information, mission, and values
- **FAQs** (`/faqs`) - Frequently asked questions with interactive accordion
- **Terms & Conditions** (`/terms`) - Legal terms and service conditions
- **Privacy Policy** (`/privacy`) - Data protection and privacy information
- **Refund Policy** (`/refund`) - Customer satisfaction and refund process

### Landing Page Sections
- **Hero Section** - Full-screen hero with compelling copy and CTAs
- **Why Ratoo?** - Unique selling propositions with animated cards
- **Features Showcase** - Key features with alternating layouts
- **Testimonials** - Customer reviews with carousel functionality
- **App Download** - Prominent section with store links and QR codes
- **Footer** - Comprehensive footer with all legal and social links

### Key Functionality
- **Phone Call Integration** - Direct phone links for ordering
- **App Store Links** - Download buttons for iOS and Android
- **Smooth Navigation** - Fixed navigation with scroll effects
- **Interactive Elements** - Hover effects and micro-interactions
- **Performance Optimized** - Fast loading with Next.js optimizations

## 🛠️ Technology Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Font**: Inter (Google Fonts)
- **Language**: TypeScript
- **Deployment**: Vercel-ready

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd ratoo-website
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 🎨 Design System

### Colors
- **Primary**: Blue gradient (`#3B82F6` to `#8B5CF6`)
- **Secondary**: Purple and blue variations
- **Background**: White, light gray, and gradient backgrounds
- **Text**: Dark gray for headings, medium gray for body text

### Typography
- **Font Family**: Inter (Google Fonts)
- **Headings**: Bold weights with gradient text effects
- **Body Text**: Regular weight with optimal line height

### Components
- **Buttons**: Primary and secondary button styles with hover effects
- **Cards**: Rounded corners with shadows and hover animations
- **Navigation**: Fixed header with smooth scroll effects
- **Sections**: Consistent padding and responsive layouts

## 📱 Responsive Design

The website is fully responsive and optimized for:
- **Mobile**: 320px - 768px
- **Tablet**: 768px - 1024px
- **Desktop**: 1024px+

## ⚡ Performance Features

- **Next.js Image Optimization** - Automatic image optimization
- **Code Splitting** - Automatic code splitting for faster loading
- **Static Generation** - Pre-rendered pages for optimal performance
- **Lazy Loading** - Components load as needed
- **Optimized Animations** - Hardware-accelerated animations

## 🔧 Customization

### Updating Content
- **Company Information**: Update content in respective page components
- **Contact Information**: Modify phone numbers and emails in components
- **App Store Links**: Update placeholder URLs in download sections
- **Social Media**: Update social media links in the footer

### Styling Changes
- **Colors**: Modify CSS variables in `globals.css`
- **Typography**: Update font settings in `layout.tsx`
- **Animations**: Adjust animation parameters in components
- **Layout**: Modify Tailwind classes in components
